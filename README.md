## What it does

`main.py` writes exactly one word — the first word that came to mind — to `/output/entry.txt`, UTF-8, with no trailing newline. It then reads the file back and verifies it matches byte for byte, exiting with an error on any mismatch.

## The word

```
Mooncrumb
```

## Run

```sh
python3 main.py
```
